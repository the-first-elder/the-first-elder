# Mayowa Abikoye

Smart contract engineer and Web3 security researcher, about four years in Web3. I build DeFi protocols and agent tooling in Solidity, Rust and Cairo, plus the front ends that go with them in React and Next.js.

## Worth opening
- UNIT - turns a natural language prompt into a multi-step onchain execution plan, and records every step onchain via ERC-8004 with a reputation score. Live: https://unit-jkz9.vercel.app
- CrabSwap - cross-chain arbitrage using Pyth price feeds, Across bridging and Uniswap v4 pools
- JIT-UNISWAP-V4-HOOK - just-in-time liquidity hook built on Chainlink price feeds, from the Uniswap Hook Incubator cohort 2 (July 2024)

Also here: a Rust zk commitment scheme example, and a DEX aggregator I built as a custom implementation and ran live at my last startup https://x.com/mace_ag.

## Stack
